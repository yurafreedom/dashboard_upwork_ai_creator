# Бюро проектов

[Открыть дашборд](https://yurafreedom.github.io/dashboard_upwork_ai_creator/)

Постоянный архив Upwork для Yuriy: проекты, оригинальные описания клиентов, учебные разборы, сохранённые Cover Letter, цены, ответы и отчёты. Все эти материалы опубликованы по прямому разрешению владельца от 21.11.2026. Старые условия и статусы относятся к указанному времени проверки.

## Работа из любого чата или компьютера

Нужны Python 3.10+, Git и право push в этот репозиторий. Авторизация Upwork MCP проверяется отдельно в каждой среде; сайт и GitHub Actions не выполняют поиск и не содержат OAuth-токены.

```sh
git clone https://github.com/yurafreedom/dashboard_upwork_ai_creator.git
cd dashboard_upwork_ai_creator
python3 sync_github.py pull
```

В новом чате дай ссылку на репозиторий и поручение:

> Продолжи поиск Upwork для Yuriy в репозитории https://github.com/yurafreedom/dashboard_upwork_ai_creator. Сначала получи актуальный main и прочитай AGENTS.md. Сохрани результаты, оригиналы описаний и учебные разборы в этом репозитории. В конце выполни python3 sync_github.py publish --wait и проверь обновление GitHub Pages.

Перед поиском: `python3 sync_github.py pull`, проверка подключения, `python3 cleanup.py --apply`. Следуй AGENTS.md и согласованным лимитам. Отчёт — `reports/live_YYYYMMDDTHHMMSSZ.md`, карточки — блок `project-cards`, учебные разборы — `data/practice.json`.

После сохранения:

```sh
python3 sync_github.py publish --wait
```

Команда проверяет архив и английские оригиналы, сохраняет изменения коммитом, получает параллельные обновления и делает обычный push. Новые записи из разных чатов объединяются по ID; исходные даты сохраняются. Неоднозначные конфликты останавливают публикацию, а локальная работа остаётся в коммите. Force-push и удаление старых карточек не используются.

`--wait` проверяет `version.json` сайта: опубликованный commit должен совпадать с отправленным. Без `--wait` подтверждается только Git push. Результат хранится локально в `.publish-state.json`. Если Actions ещё не завершился, не называй сайт обновлённым.

## Публикация

Push в `main` запускает `.github/workflows/pages.yml`: тесты → сборка статического сайта → GitHub Pages. Дашборд работает без включённого Mac. Новые данные появляются после выполненного поиска, push и успешной публикации, а не автоматически при появлении вакансии на Upwork.

На GitHub Pages доступны каталог, практика, оригинальные английские описания, личные отклики, отчёты и файлы внутри `applications/`. Внешние локальные пути из старых писем остаются историческими ссылками на файлы; они не означают, что файл загружен.

Файлы авторизации, `.env`, ключи, `connection_status.json`, временные файлы и локальная история доставки не публикуются. На новом устройстве команда синхронизации создаёт непроверенный `connection_status.json` из шаблона. Наличие репозитория не подтверждает доступ к аккаунту Upwork.

## Локальная проверка

```sh
python3 -m unittest discover -s tests -v
python3 build_site.py
python3 -m http.server 47322 --bind 127.0.0.1 --directory dist
```

Открыть `http://127.0.0.1:47322/`. Исходный локальный вариант с динамическим чтением архива: `python3 site/server.py --open`.
